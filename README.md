# ☕ Coffee Heaven – Responsive Coffee Brand Website

## 📌 Project Overview

**Coffee Heaven** is a responsive coffee brand website developed using HTML5 and CSS3 as part of my Web Development Internship.

This project is an improved version of my initial website created for **Internship Task 1**. The original version included a basic sidebar, a coffee-themed hero section, and a collection of coffee images. In this updated version, I have expanded the website by adding dedicated Home, About, Menu, and Contact sections, improving responsiveness, and enhancing the overall layout and presentation.

The main objective of this project is to create an attractive and user-friendly website that presents a coffee brand and its products in an organized manner.

## 📱 Responsive Design

The website uses CSS media queries to support desktop, tablet, and mobile devices.

### Desktop

- Displays the sidebar alongside the main content.
- Uses a horizontal layout for the main website structure.
- Arranges product images in a flexible row.

### Tablet

- Adjusts sidebar width and typography.
- Reduces product image dimensions.
- Maintains a flexible layout for the available screen space.

### Mobile

- Places the sidebar above the main content.
- Displays navigation links horizontally and allows them to wrap.
- Arranges product images vertically.
- Adjusts font sizes, padding, and spacing for smaller screens.

The website uses Flexbox, flexible widths, and multiple media queries to improve usability across different devices.

## 🚀 How to Run the Project

1. Clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html`, `internship task 1.css`, and `coffee.jpeg` are in the correct locations.
4. Open `index.html` in your web browser or use the Live Server extension.
5. Use the navigation links to explore the Home, About, Menu, and Contact sections.
6. Resize the browser window to test the responsive layout.

## 🧭 Navigation

The navigation menu uses HTML anchor links to move between sections on the same page.

| Navigation Link | Destination |
|---|---|
| Home | `#home` |
| About | `#about` |
| Menu | `#menu` |
| Contact | `#contact` |

Each link points to a corresponding HTML section through its `id` attribute. This allows visitors to navigate the website without opening separate pages.
